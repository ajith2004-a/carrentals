## AWS Deployment

The application is deployed on an AWS EC2 Ubuntu instance using the LAMP stack.

# Deployment Components

- AWS EC2 - Virtual server
- Ubuntu - Operating system
- Apache - Web server
- MySQL - Database
- PHP - Application backend

# Deployment Process

1. Created an AWS EC2 instance.
2. Connected to the EC2 instance using EC2 Instance Connect.
3. Installed and configured Apache.
4. Installed PHP.
5. Installed and configured MySQL.
6. Created the application database and user.
7. Uploaded the Car Rental application to the EC2 instance.
8. Configured the PHP application to connect to MySQL.
9. Restarted Apache.
10. Accessed the website using the EC2 public IP address.
